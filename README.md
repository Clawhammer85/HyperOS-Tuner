# HyperOS-Tuner
Beschleunigt das OS und stellt DNS auf gewünschte Anbieter. 

Android-App für Xiaomi, Redmi und POCO mit HyperOS: Checkliste mit empfohlenen Einstellungen für Datenschutz, Werbung und Geschwindigkeit, Direktsprung in die richtigen Menüs und automatischer Erkennung einiger Systemwerte. Optional per ADB: Werte automatisch setzen und Werbedienste entfernen.
